# Keyboard

Shortcuts work when you're not typing in a box.

## Everywhere

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | The command palette: jump to a PR or repository, run an action |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Collapse or show the PR list |
| <kbd>F5</kbd> | Refresh |

In a PR's own window (popped out), <kbd>Ctrl</kbd>+<kbd>K</kbd> and <kbd>Ctrl</kbd>+<kbd>B</kbd> do nothing, and <kbd>F5</kbd> reads that PR again.

## A pull request

| Keys | Does |
|---|---|
| <kbd>R</kbd> | Start a review |
| <kbd>Esc</kbd> | Stop the running review (or stop editing a finding) |
| <kbd>J</kbd> / <kbd>K</kbd> | Next / previous finding |
| <kbd>A</kbd> / <kbd>E</kbd> / <kbd>D</kbd> | Keep / edit / dismiss the finding |
| <kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> | Layout: the diff, both side by side, the panel |
| <kbd>F</kbd> | Show or hide the file list |
| <kbd>/</kbd> | Filter the files (<kbd>↑</kbd> / <kbd>↓</kbd> open the previous / next one, <kbd>Esc</kbd> clears) |
| <kbd>W</kbd> | The diff: only the changes, or the whole file |
| <kbd>C</kbd> | Comment on the selected lines of the diff |
| <kbd>Ctrl</kbd> + scroll | Text size of the review and comments panel |

## Fix mode

| Keys | Does |
|---|---|
| <kbd>Enter</kbd> | Send your message (<kbd>Shift</kbd>+<kbd>Enter</kbd> for a new line) |
| <kbd>End</kbd> | Go to the latest message |
| <kbd>F</kbd> | On Changes: show or hide the list of files |
| <kbd>F5</kbd> | Read the folder's changes again |

## The command palette

<kbd>Ctrl</kbd>+<kbd>K</kbd>, then type. It finds PRs by title or number, repositories, projects, and actions such as:

- Run a review on this PR
- Review & post kept comments…
- Export this review to Markdown…
- Switch project…, Switch to GitHub / Azure DevOps
- Review focus areas…
- Larger / smaller text in the review panel
- What's new, Check for updates, Settings
